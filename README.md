# Dominat-Isoforms-in-the-Human-Transcriptome
Analyzed isoform dominance in human transcriptomes using LCL RNA-seq (Geuvadis dataset). Identified that most genes consistently express a single dominant isoform, with apparent switching largely driven by low-expression noise. Applied TPM filtering to reveal biologically meaningful isoform patterns and evaluated concordance with MANE_Select.

code/analysis.py is the file that has the pipeline. The rest of the files include code to generate plots. 

All plots can be found in the code/plots folder
